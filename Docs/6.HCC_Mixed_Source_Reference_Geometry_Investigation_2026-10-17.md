# HCC Mixed Source-Reference Geometry Investigation
Date: 2026-10-17

## Purpose
Document the source-reference and CT geometry findings for HCC_068, HCC_091, HCC_094, HCC_097, HCC_099, HCC_101, and HCC_103.

## Verified findings
- Each patient had exactly one SEG object in the inspected local folder.
- All inspected SEG frames had readable plane positions.
- All source references in the audit resolved to local CT instances.
- Each patient's inspected references resolved to one CT series.
- Every source reference had the DICOM purpose code DCM:121322, "Source image for image processing operation."
- For every frame with two references, both references belonged to the same CT series and represented consecutive CT planes.
- One reference was at zero normal offset; the second was separated by the measured adjacent-plane gap.

## Interpretation
The mixed offsets are explained geometrically by multiple source references to consecutive CT planes within the same referenced series. The extra references are present in the SEG source-reference metadata; they are not merely duplicate rows generated by the comparison audit.

The findings do not establish which source reference should be preferred for every downstream use, why the segmentation workflow recorded multiple references, or whether each annotation is semantically correct.

## Handling decision
- Preserve original CT and SEG files and all source references.
- Do not shift masks, edit DICOM metadata, or invent a spatial transform based on these findings.
- Treat these seven patients as having characterized source-reference geometry, with annotation quality and downstream mapping policy still subject to review.
- Do not label these patients training-ready based on geometry alone.
